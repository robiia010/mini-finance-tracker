   # 💰 Mini Finance Tracker

A lightweight, terminal-based personal finance manager written in Python.

##  Features
- Real-time Balance: Keep track of your current funds.
- Income & Expense: Easily add or subtract transactions.
- Auto-Save: All data is automatically stored in a data.json file.
- Minimalist: Simple, clean code for quick financial logging.

##  Getting Started
To run this project, make sure you have Python installed on your computer.

1. Download the file: main.py
2. Run the following command in your terminal:
   bash
   python main.py
